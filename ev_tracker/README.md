# EV Tracker 2.3.7

Україномовне доповнення для Home Assistant з обліком електромобіля, заряджань, окупності та сезонної витрати. Докладні можливості, вимоги й попередження див. у [головному README](../README.md).

Працює через Home Assistant Ingress; налаштування зберігаються в `/data/options.json`, дані — в `/data/ev.db`.

Після зміни коду необхідно перебудувати (Rebuild) доповнення та перезапустити його. Зміни версії описано в [нотатках 2.3.7](RELEASE_NOTES_2.3.7.md).
